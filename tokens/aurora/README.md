# Aurora Token Layer

Target hierarchy:

```
primitive
  → semantic
  → aurora behavior
  → component consumption
```

Planned groups:

- spectrum
- atmosphere
- collage
- depth
- material
- motion

Prefer Design Tokens Community Group compatible syntax using `$type`, `$value`, and `$description`.

Do not establish final primitive values until the visual-language audit identifies evidence and relationships.

Aurora-specific tokens should describe behavior and semantics rather than duplicate generic primitives.
