# Aurora Artifacts

This directory is for generated or builder-produced evidence that supports decisions.

Expected early outputs:

- `repo-audit.md`
- `baseline-command-results.md`
- `qa-baseline.md`
- `qa-report.md`
- `performance-report.md`
- `accessibility-report.md`
- `build-receipt.json`

Artifacts should record the exact commit SHA they evaluate.

Do not treat an artifact as canonical architecture simply because it exists here.
