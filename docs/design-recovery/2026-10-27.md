### D35 — Aurora and Midnight: recover the collage source before formalizing a new system

**Use when:** When resuming Aurora collage UI, midnight bento components, image-derived palette/layout studies, or related missing-source work.

[Recovered evidence] A Drive folder named aurora-collage-ui-system was found but returned no children in this listing; qt314wink/aurora README retrieval did not resolve. This is an access/source gap, not a conclusion that the project never existed.

[Adjacent recovered direction] midnightbento.txt describes a MidnightForestGrid, moonlit bark/glow, variable typography, magnetic card motion, fluid grids, device-responsive atmosphere, SVG texture, and multiple animation libraries. It is adjacent material retrieved through an Aurora search; authorship/derivation into Aurora is unproven.

[Repair resolution — proposed] Do not rename Midnight as Aurora or invent a missing collage canon. Recover original reference images, build prompt, asset library, and the actual repo/branch/archive. Audit illustrative code before reuse: browser globals during render, mixed motion-value APIs, whole-grid displacement, resource cleanup, and gesture/focus equivalence need explicit integration tests.

[Reimagined option — hypothesis] If the original supports it, Aurora could become a composition system for layered image, paper, color, and editorial fragments, with selective midnight/aurora atmospheres and usable asset provenance. This is a new candidate direction, not recovered canon.

[Carry-forward test] Establish one source-backed composition with an explanation of what came from which reference, what remains adjustable, and which parts survive static/mobile presentation. Keep the unresolved identity visible until originals are found.
